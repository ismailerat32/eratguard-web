EratGuard PRO Privacy Policy

Last updated: August 31, 2026

EratGuard PRO is an Android SMS application designed to function as the user's default SMS handler and provide SMS management and spam protection features.

SMS Permissions

EratGuard PRO may request SMS-related permissions including READ_SMS, RECEIVE_SMS, SEND_SMS, RECEIVE_MMS and RECEIVE_WAP_PUSH. These permissions are used only to provide the application's core messaging, SMS management and spam protection functionality.

SMS access is requested only when required for these features and after the user chooses to use EratGuard PRO as their default SMS application where required by Android.

SMS and Message Data

Message content accessed by EratGuard PRO is used to provide core messaging and spam protection functionality. EratGuard PRO does not sell SMS or message data to third parties and does not use message content for advertising.

Data Sharing

EratGuard PRO does not sell personal or sensitive user data. SMS and message data is not shared with third parties for advertising or marketing purposes.

User Control

Users control Android permissions through their device settings and may change their default SMS application at any time through Android system settings.

Security

Reasonable safeguards are used to protect information handled by the application. Access to sensitive Android permissions is limited to functionality necessary for EratGuard PRO's core features.

Changes to This Policy

This Privacy Policy may be updated when EratGuard PRO functionality or data practices change. Updates will be published on this page.

Contact

For privacy questions or requests concerning EratGuard PRO, please contact the developer through the official EratGuard project channels.
